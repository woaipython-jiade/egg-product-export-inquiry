## 市场准入概览

日本对某些中国蛋品开放，但处于**高度监管和条件敏感**的框架下。两个部委共同管控进口：

- **厚生劳动省（MHLW）** — 食品安全、进口检查、残留标准
- **农林水产省（MAFF）** — 动物检疫、HPAI管控

准入状态为"受限" — 贸易在法律上可行，但取决于严格合规，且可能因禽流感事件而迅速中断。

### 关键事实

- 日本**肯定列表制度**为约800种物质设定MRL；其他一律默认**0.01 ppm**
- 进口检查采用**三级递进**体系（书面审查→监测检查→命令检查）
- 中国发生**HPAI暴发**会触发省级进口暂停，可能持续数月
- 日本是全球**最大的鸡蛋净进口国**（按价值计） — 高价值目标市场

## 进口通报系统：FAINS/NACCS

所有食品进口日本须通过**食品自动进口通报检查系统（FAINS）**，该系统与日本通关系统**NACCS（日本自动化货物港口综合系统）**集成。

### 流程

1. **进口通报**：日本进口商通过FAINS/NACCS向入境口岸的MHLW检疫站提交"食品等进口申报书"（食品等輸入届出書） — **须在货物放行之前**

2. **书面审查**：MHLW检疫官员审核通报、卫生证书及支持文件

3. **检查判定**：根据产品类别、原产国和合规历史，货物被分配以下三个检查级别之一

### 三级检查体系

| 级别 | 名称 | 触发条件 | 处理方式 |
|------|------|---------|---------|
| **第一级** | 书面审查 | 合规记录良好为默认 | 审核文件；合格即放行 |
| **第二级** | 监测检查 | 常规监测（约30%货物） | 随机抽样和实验室检测；货物可在结果出来前有条件放行 |
| **第三级** | 命令检查（命令検査） | 检测发现违规 | **100%检查** — 每批货物均须检测；货物须等结果确认后方可放行 |

### 递进机制

- 监测检查发现违规 → 提升至**加强监测（30% → 50%抽样率）**
- 违规持续 → 提升至**命令检查（100%检测）**
- 命令检查状态会在MHLW网站**公开列示**，即使采取纠正措施后仍可能持续**6–12个月**
- 降级需要在多批货物中展示清洁的合规记录

## 肯定列表制度（ポジティブリスト制度）

肯定列表制度是蛋品合规的最关键要求：

### 运作机制

| 类别 | 处理方式 |
|------|---------|
| **已设定MRL的列入物质** | 约800种农用化学品和兽药，按食品品种设定具体最大残留限量 |
| **豁免监管的物质** | 约65种被认为任何水平均安全的物质 |
| **其他所有物质** | 默认统一限量**0.01 ppm** — 实际上等同零容忍 |

### 蛋品关键MRL

请在官方**FFCR（食品与食品化学研究基金会）MRL数据库**查询当前限值：

| 物质 | 蛋中MRL | 备注 |
|------|---------|------|
| 恩诺沙星（氟喹诺酮类） | 0.01 ppm（默认值） | **高度敏感** — 中国产品有历史违规记录 |
| 氯霉素 | 不得检出 | 全球零容忍 |
| 氟虫腈 | 0.02 ppm | 欧盟氟虫腈危机提升了全球关注 |
| 尼卡巴嗪 | 0.01 ppm（默认值） | 抗球虫药 — 须确保停药期 |
| 三聚氰胺 | 非肯定列表物质 — 另行监管 | 按MHLW风险评估 |

### FFCR MRL数据库

**官方查询工具**：[http://db.ffcr.or.jp/front/](http://db.ffcr.or.jp/front/)
- 按物质名称（英文或日文）和食品类别"蛋类"搜索
- 这是确认具体MRL值的**权威来源**
- MHLW修订标准时数据库同步更新

## 动物检疫（农林水产省）

### HPAI（高致病性禽流感）管控

MAFF维护基于HPAI暴发的**动态暂停清单**：

- **机制**：中国某省确认HPAI时，MAFF暂停**来自该特定省份**的家禽和蛋品进口
- **范围**：暂停涵盖壳蛋，可能涵盖加工蛋制品（取决于热处理状态）
- **持续时间**：暂停持续至该省被OIE/WOAH宣布HPAI清净，另加等待期
- **当前状态**：请查阅MAFF网站获取最新暂停清单

**MAFF动植物检疫所**：[https://www.maff.go.jp/aqs/english/](https://www.maff.go.jp/aqs/english/)

### 热处理蛋制品

经过充分热处理的加工蛋制品（如蛋粉、巴氏杀菌液蛋）可能**豁免HPAI相关暂停**，因为病毒被热灭活。但须注意：
- 具体热处理参数须有文件记录
- MAFF逐案判定
- 发运前请咨询MAFF检疫站

## 标签要求（食品表示法）

日本**《食品表示法》（食品表示法）**和**《食品表示标准》（食品表示基準）**规定所有标签要求：

### 强制标签要素

| 要求 | 详情 |
|------|------|
| 语言 | **日语**（强制） |
| 产品名称 | 按食品类别标准规定命名 |
| 配料表 | 按重量递减排列 |
| **过敏原声明** | **蛋（卵）是8种特定原材料之一** — 须醒目声明 |
| 净重 | 公制单位（g或kg） |
| 日期标示 | 赏味期限（賞味期限）或消费期限（消費期限） |
| 保存方法 | 温度和条件 |
| 原产国 | "原産国名：中国" |
| 进口商名称和地址 | 完整的日本商业地址 |
| 营养标签 | 能量、蛋白质、脂肪、碳水化合物、钠（以食盐当量显示） |

### 过敏原声明 — 极其重要

蛋（卵/たまご）是日本**8种特定原材料（特定原材料）之一**，**必须**声明。这是法律强制要求，非自愿。未声明蛋过敏原属于严重违规。

## 风险提示

- **肯定列表违规触发命令检查（100%检测）** — 这会被公开列示，对商业极具破坏性；一次违规可影响所有货物6–12个月
- **氟喹诺酮类残留（恩诺沙星、环丙沙星）**历史上是中国产品最常见的违规项 — 确保绝对零残留
- **HPAI暂停按省份执行但极为迅速** — 一个确认病例可在数天内关闭该省出口
- **日本的检查结果由MHLW公开发布** — 违规对所有进口商和竞争对手可见
- **0.01 ppm默认限量**意味着任何未专门列入的物质实际上被禁止 — 全面的出货前检测至关重要
- **检疫站进口通报处理时间**可能为1–3个工作日；命令检查额外增加7–14天等待实验室结果

## 行动清单

- [ ] 确认海关总署注册明确涵盖对日出口
- [ ] 在FFCR MRL数据库（[db.ffcr.or.jp](http://db.ffcr.or.jp/front/)）中查询生产使用的所有物质
- [ ] 检测**氟喹诺酮类**（恩诺沙星、环丙沙星） — 须<0.01 ppm
- [ ] 按完整肯定列表参数检测，不仅限于中国GB标准
- [ ] 查阅MAFF HPAI暂停清单确认您的生产省份状态
- [ ] 确定您的产品是否符合HPAI热处理豁免条件
- [ ] 联系有FAINS/NACCS进口通报经验的日本进口商
- [ ] 准备带有强制过敏原声明（卵）的日语标签
- [ ] 标注符合《食品表示标准》的营养标签
- [ ] 在物流中预留2–3周缓冲时间应对可能的检查延误
- [ ] 关注MHLW中国蛋品进口检查结果
