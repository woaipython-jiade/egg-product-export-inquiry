## 市场准入概览

马来西亚对中国蛋品出口商是重要机遇，但需通过**三层强制授权**：

1. **DVS设施注册** — 中国加工厂须经马来西亚兽医局注册批准
2. **JAKIM认可清真认证** — 产品须持有JAKIM认可机构颁发的清真证书
3. **MAQIS进口许可** — 每批货物需单独许可

> **重要更新（2025年2月）**：JAKIM撤销了对**中国伊斯兰教协会（CIA）**的认可——此前CIA是中国最大的清真认证机构。宽限期已于**2025年8月19日**届满。仅持有CIA清真认证的产品将在**马来西亚边境被拒绝入境**。详见下文。

### 关键事实

- **穆斯林人口**：约占3300万总人口的63% — 清真合规对主流市场准入至关重要
- **首要把关机构**：DVS（兽医局）——非卫生部——是蛋品进口的主要管理机构
- **法规框架**：**1983年《食品法》**和**1985年《食品条例》**管辖食品安全标准
- **清真主管机构**：JAKIM是马来西亚清真认可的唯一权威机构
- **检疫主管机构**：MAQIS负责边境检查和进口许可

## 第一层：DVS设施注册（准入前提）

DVS是蛋品进口的**首要把关机构**。中国加工设施须经DVS注册批准后方可发货。

### DVS要求文件

官方要求已发布于：
- **DVS R5**（2024年7月29日修订）："马来西亚蛋粉进口要求"
  - [DVS R5 PDF](https://www.dvs.gov.my/dvs/resources/user_1/2025/BKPBV/IMPORT%20EKSPORT/(R5)_Egg_Products-Any_Country-_Revised_290724.pdf)
- **通用程序**：[肉类、禽类、乳制品和蛋品进口程序（2023年3月）](https://www.dvs.gov.my/dvs/resources/user_1/2023/BRV/LOJI%20LUAR%20NEGARA/UPDATE_MARCH_2023.GENERAL_PROCEDURE_IMPORT_MEAT,_POULTRY,_MILK_AND_EGG_PRODUCTS_TO_MALAYSIA_.REV_1_._30012023_.pdf)

### 注册流程

| 步骤 | 操作 | 详情 |
|------|------|------|
| 1 | 填写申请表 | **DVS/BRV/APP/1a**（第5版，2025年1月）— [续期申请表（第5版）](https://www.dvs.gov.my/dvs/resources/user_1/2025/BRV/LOJI%20LUAR%20NEGARA/2._APPLICATION_FORM_FOR_RENEWAL_EXPORT_MEAT,_POULTRY,_MILK,_EGG_AND_PRODUCTS_TO_MALAYSIA_RENEWAL_rev_.5_.pdf) |
| 2 | GACC背书 | 申请表须经中国兽医主管机构（GACC）签字/背书 |
| 3 | DVS风险评估 | 马来西亚DVS进行基于SPS的评估 |
| 4 | 现场检查 | DVS可能赴中国工厂进行现场检查 |
| 5 | 设施登录 | 批准后，设施被录入**e-Dagang**系统 |

**时间**：DVS设施注册可能需要**数月**，包括风险评估和可能的现场检查。请提前规划。

### 兽医卫生证书（逐批要求）

每批货物须附有GACC签发的**英文官方兽医卫生证书（VHC）**，**须在发运7日内签发**，证明：

1. 原产国/地区在过去**12个月内**持续**无禽流感、新城疫和禽霍乱**；出口日期前28天内无暴发
2. 蛋来自经认可的**无鸡白痢沙门氏菌和肠炎沙门氏菌**的养殖场；出口前6个月内农场未诊断出传染性禽病
3. 蛋品在政府兽医监督下**经批准的加工厂**加工
4. 产品经**加工处理确保灭活禽流感病毒和新城疫病毒**（符合WOAH建议）
5. 产品在卫生条件下**加工、包装和储存**，不含防腐剂、色素、残留或有害物质

## 第二层：JAKIM清真认证

### CIA认可被撤销——2025年2月

**自2025年2月19日起**，JAKIM撤销了对**中国伊斯兰教协会（CIA）**的认可：

- [JAKIM官方公告](https://myehalal.halal.gov.my/portal-halal/v1/index.php?data=bW9kdWxlcy9jb250ZW50X2RldGFpbHM7Ozs%3D&page_title=Announcement&content_id=2025031367d238e5c4bba)
- 宽限期已届满：**2025年8月19日**（已过期）
- 仅持有CIA清真认证的产品将在**马来西亚边境被拒绝入境**

### 当前获认可的中国清真认证机构（截至2025年2月）

| 序号 | 认证机构 | 所在地 |
|------|---------|--------|
| 1 | **山东清真认证服务中心（SHC）** | 山东济南 |
| 2 | **ARA清真认证服务中心（ARA）** | 河南郑州 |
| 3 | **临夏清真食品认证中心** | 甘肃临夏 |
| 4 | **陕西尚品源清真食品餐饮管理有限公司（SSPY）** | 陕西 |
| 5 | **重庆清真认证服务中心（HCS）** | 重庆 |

**查阅最新名单**：[JAKIM FHCB名单](https://myehalal.halal.gov.my/portal-halal/v1/index.php?data=bW9kdWxlcy9jb2xsYXBzaWJsZV9jb250ZW50Ozs7Ow%3D%3D&utama=CB_LIST)

- PDF（2025年2月25日）：[CBLIST-25FEBRUARY2025.pdf](https://myehalal.halal.gov.my/portal-halal/v1/pdf/cb/CBLIST-25FEBRUARY2025.pdf)
- PDF（2025年8月29日）：[FHCB29082025.pdf](https://myehalal.halal.gov.my/portal-halal/v1/pdf/cb/FHCB29082025.pdf)

### 清真认证流程

1. **从上述名单中选择一家获认可的CB**
2. **设施审核** — 清真CB审核生产设施、原料采购、交叉污染控制、员工培训、仓储物流
3. **原料验证** — 所有投入品须符合清真要求（酶、乳化剂、包装胶粘剂/油墨、清洁化学品）
4. **证书颁发** — 有效期1-2年（取决于CB）
5. **持续合规** — 年度监督审核；证书续期

**时间**：初次认证从申请到获证**6-12个月**。

| **FOSIM** | [fsis2.moh.gov.my/fosimv2](http://fsis2.moh.gov.my/fosimv2/) | 卫生部食品安全信息系统 |

- 注册信息：[MAQIS进口商注册](https://imaqis.maqis.gov.my/SPEED/#!/login)
- 未注册进口农产品属**违法行为**。

### 每批货物所需文件

| 文件 | 签发方 |
|------|--------|
| 有效MAQIS进口许可 | MAQIS（通过e-Permit） |
| 英文兽医卫生证书 | GACC/地方海关 |
| JAKIM认可清真证书 | 认可的中国CB |
| 检验分析报告 | 认可实验室 |
| 原产地证书 | 中国贸促会/海关 |
| 商业发票 | 出口商 |
| 装箱单 | 出口商 |
| 提单/空运单 | 承运人 |

### 边境检查

MAQIS官员在入境口岸进行：
1. **文件核验** — 检查VHC、进口许可、清真证书
2. **e-Dagang核验** — 确认货物来自DVS注册设施
3. **实物检查** — 包装完整性、标签合规、温度检查
4. **抽样** — 可能进行实验室检测
5. **放行或扣留** — 合规货物放行；不合规货物扣留、退运或销毁

## 食品安全标准（1985年《食品条例》）

### 蛋品标准

1985年《食品条例》**第八部分**包含蛋品具体标准：

| 条例 | 产品 |
|------|------|
| 第171条 | 蛋（一般定义） |
| 第172条 | 液蛋 |
| 第173条 | 液态蛋黄 |
| 第174条 | 液态蛋白 |
| 第175条 | 蛋粉、蛋黄粉、蛋白粉 |
| 第176-178条 | 其他蛋品标准 |

全文：[1985年《食品条例》（2024年10月更新）](https://hq.moh.gov.my/fsq/xs/dl.php?filename=Food+Regulation+1985+Update+291024+(PUA+209_2020).pdf)

### 微生物标准

| 检测项目 | 要求 |
|---------|------|
| 沙门氏菌 | 25g中不得检出 |
| 大肠杆菌 | 按《食品条例》限值 |
| 需氧菌落计数 | 按产品类别 |
| 金黄色葡萄球菌 | 加工蛋制品 |

### 化学污染物限值

| 污染物 | 法规依据 |
|-------|---------|
| 铅、镉、汞 | 1985年《食品条例》附表十四 |
| 兽药残留 | 与食品法典委员会一致 |
| 农药残留 | 附表十六 |
| 黄曲霉毒素 | 《食品条例》（严格执法） |

### 标签要求（1985年《食品条例》）

| 要求 | 详情 |
|------|------|
| 语言 | **马来语或英语**（强制）；可附加其他语言 |
| 产品名称 | 食品的准确描述 |
| 配料表 | 按重量递减排列 |
| 净重/净含量 | 公制单位 |
| 日期标示 | "最佳食用期限"或"食用期限" |
| 制造商/包装商 | 名称和营业地址 |
| 进口商 | 马来西亚境内名称和营业地址 |
| 原产国 | 所有进口食品强制标示 |
| 清真标识 | 如获认证——须按JAKIM规定标识格式 |
| 营养面板 | 能量、蛋白质、碳水化合物、总糖、脂肪、钠 |
| 过敏原声明 | 蛋类为强制过敏原 |
| 字体大小 | 最小**10号字体**；醒目突出 |

## 风险提示

- **CIA认可撤销是最关键变化** — 仅持有CIA清真认证的产品将被拒绝入境。须立即转换至剩余5家认可CB之一
- **DVS设施注册需数月** — 请在计划发货前充分提前启动流程
- **JAKIM认可名单定期变化** — 投资认证前核实任何机构的当前状态
- **VHC须证明HPAI/ND无疫** — 中国暴发疫情可触发立即暂停进口
- **e-Dagang电子核验** — MAQIS在边境电子查验设施注册状态；未注册设施的产品将被拒绝
- **宗教敏感性** — 任何清真不合规的印象都可能在马来西亚造成严重、持久的市场损害
- **标签合规** — 标签须使用马来语或英语，包含所有强制字段和营养面板

## 行动清单

- [ ] 确认海关总署注册有效（第249号令）
- [ ] **确认CIA清真证书已失效** — 如您的设施使用CIA认证，须从认可CB重新获取认证
- [ ] 从中国剩余5家JAKIM认可CB中选择一家（SHC、ARA、临夏、SSPY或HCS）
- [ ] 完成清真设施审核并获得证书（预算6-12个月）
- [ ] 提交DVS设施注册申请（表格DVS/BRV/APP/1a）并附GACC背书
- [ ] 等待DVS风险评估和可能的现场检查
- [ ] 确保马来西亚进口商在MAQIS（SPEED）和MOH（FOSIM）注册
- [ ] 进口商在每批发运前通过e-Permit申请MAQIS进口许可
- [ ] 从GACC获取包含全部5项证明的兽医卫生证书
- [ ] 准备符合1985年《食品条例》（第171-178条）的**马来语或英语**标签
- [ ] 包含营养面板（能量、蛋白质、碳水化合物、糖、脂肪、钠）和过敏原声明
- [ ] 关注HPAI动态和DVS公告应对贸易中断
- [ ] 向[JKDM HS Explorer](https://ezhs.customs.gov.my/)查询当前进口税率——考虑使用ACFTA原产地证书（Form E）享受优惠税率
