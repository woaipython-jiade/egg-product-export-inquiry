## 市场准入概览

加拿大通过**双主管机构框架**监管蛋品进口：**加拿大食品检验局（CFIA）**负责进口许可和边境检查，**加拿大卫生部（Health Canada）**依据《食品和药品法》制定食品安全标准。

### 关键事实

- **法规框架**：**《加拿大安全食品法》(SFCA)** 和 **《加拿大安全食品条例》(SFCR)** — 2019年取代原有《蛋类条例》
- **首要把关机构**：CFIA — 签发安全食品许可证(SFC Licence)并管控AIRS系统
- **进口资格**：通过**AIRS数据库**逐产品、逐国家确定
- **供给管理**：加拿大蛋品行业实行供给管理制度；但**加工蛋品**（干燥、液态、冷冻）面临的贸易壁垒低于壳蛋
- **关税考量**：WTO关税配额（TRQ）适用于部分蛋品；配额外关税可超过15%

### 准入状态

中国的资格因其**HPAI（高致病性禽流感）状况而复杂化**。CFIA的动物卫生要求（2024年12月更新）要求出口国/地区/区域的HPAI和vND无疫认证。但**加工蛋品**若加工处理可灭活HPAI和vND病毒（喷雾干燥、充分巴氏杀菌），可能符合**WOAH陆生动物卫生法典第10.4.23条和第10.9.20条**的要求。

每种产品需在AIRS中逐一核实是否符合中国来源的进口资格。关键要求包括：

1. **AIRS资格** — 特定产品须有来自中国的进口资格（须直接查询AIRS获取当前状态）
2. **SFC许可证** — 加拿大进口商须持有有效许可证（审批约需70个工作日）
3. **EIPA进口许可** — 蛋类列入进口管制清单（第135-139项）；需TRQ配额分配或通用进口许可100号
4. **动物卫生证书** — 由GACC签发，证明HPAI/vND状况或符合WOAH规定的加工处理
5. **食品安全合规** — 符合加拿大MRL限值、微生物标准和食品添加剂规定

## 法规框架

### 《加拿大安全食品法》(SFCA) 和《加拿大安全食品条例》(SFCR)

SFCA（S.C. 2012, c. 24）和SFCR（SOR/2018-108）构成食品进口的主要法律框架：

- **SFCR第5部分** — 食品进口要求
- **SFCR第3分部** — 蛋品的特定要求
- SFCR于2019年1月15日合并取代了原有**《蛋类条例》(C.R.C., c. 284)**

| 法规 | 用途 | 链接 |
|------|------|------|
| **《加拿大安全食品法》**(S.C. 2012, c. 24) | 食品安全与进口管控主体立法 | [laws-lois.justice.gc.ca](https://laws-lois.justice.gc.ca/eng/acts/S-1.1/) |
| **《加拿大安全食品条例》**(SOR/2018-108) | 进口、许可和追溯的详细要求 | [laws-lois.justice.gc.ca](https://laws-lois.justice.gc.ca/eng/regulations/SOR-2018-108/) |
| **《食品和药品法》**(R.S.C., 1985, c. F-27) | 食品安全标准、掺假、标签 | [laws-lois.justice.gc.ca](https://laws-lois.justice.gc.ca/eng/acts/f-27/) |
| **《食品和药品条例》**(C.R.C., c. 870) | MRL、食品添加剂、成分标准 | [laws-lois.justice.gc.ca](https://laws-lois.justice.gc.ca/eng/regulations/C.R.C.,_c._870/) |

## 进口许可（CFIA）

### SFC许可证要求

所有蛋品进口商须持有CFIA签发的**安全食品许可证（SFC Licence）**：

| 项目 | 详情 |
|------|------|
| **申请系统** | My CFIA门户：[inspection.canada.ca/food-licences](https://inspection.canada.ca/en/food-licences/obtain-licence) |
| **许可类型** | 进口 — 蛋类/加工蛋品子类 |
| **审批时间** | 平均**70个工作日** — 请提前申请 |
| **预防控制计划** | 必需 — 书面PCP涵盖危害识别、关键控制点、监控程序 |
| **追溯** | 强制 — 向前一步、向后一步追溯记录 |
| **CBSA执行** | 自2021年3月15日起，无有效SFC许可证号的IID申报**自动拒绝**（[CBSA海关通知24-03](https://www.cbsa-asfc.gc.ca/publications/cn-ad/cn24-03-eng.html)） |

### AIRS（自动进口参考系统）

**AIRS数据库**是确定特定国家特定产品是否具备进口资格的权威参考：

- **AIRS门户**：[inspection.canada.ca/importing-food-plants-animals/airs](https://inspection.canada.ca/en/importing-food-plants-animals/airs)
- 采用**问答式方法**确定特定国家特定商品的资格
- AIRS规定：合格/不合格、所需文件、检查频率、条件
- 更新频繁（有时每日更新）以反映新出现的疫病情况
- **CFIA蛋品进口指南**：[inspection.canada.ca/eggs-processed-egg-products](https://inspection.canada.ca/en/importing-food-plants-animals/food-imports/food-specific-requirements/eggs-processed-egg-products)

### EIPA进口许可（进口管制清单）

蛋类和蛋品列入加拿大**进口管制清单（第135-139项）**，依据**《出口和进口许可法》(EIPA)**。除SFC许可证外，还需**进口许可**：

| 项目 | 详情 |
|------|------|
| **进口管制清单项目** | 第135-139项涵盖蛋类和蛋品 |
| **TRQ配额分配** | 进口许可签发给WTO、CPTPP或CUSMA TRQ框架下的配额持有者 |
| **无TRQ配额** | 货物按**通用进口许可100号**入境，适用显著更高的"超配额承诺"关税税率 |
| **管理机构** | 全球事务部（GAC） |
| **GAC进口商通知** | [international.gc.ca — 蛋品通知](https://www.international.gc.ca/controls-controles/prod/agri/eggs-oeufs/notices-avis/887.aspx?lang=eng) |
| **商品编码手册** | [B-27: 蛋类](https://www.international.gc.ca/controls-controles/report-rapports/list_liste/handbook-manuel/b-27.aspx?lang=eng) |

### 进口流程

| 步骤 | 操作 | 详情 |
|------|------|------|
| 1 | 核实AIRS资格 | 在AIRS中搜索特定产品+中国来源 |
| 2 | 获取SFC许可证 | 加拿大进口商通过My CFIA门户申请 |
| 3 | 准备文件 | GACC签发的卫生证书及商业文件 |
| 4 | 抵达前通知 | 通过CFIA自动进口通知系统提交 |
| 5 | 边境检查 | CFIA在指定入境口岸检查 |
| 6 | 放行或扣留 | 合规货物放行；不合规货物扣留 |

### 每批货物所需文件

| 文件 | 签发方 |
|------|--------|
| **动物卫生证书**（含HPAI/vND声明的兽医证书） | 海关总署（GACC，中国主管机构） |
| **食品安全证书**（CFIA批准格式） | 海关总署（GACC） |
| **EIPA进口许可**（TRQ配额分配或通用进口许可100号） | 全球事务部 |
| 商业发票 | 出口商 |
| 装箱单 | 出口商 |
| 提单/空运单 | 承运人 |
| 原产地证书 | 中国贸促会/海关 |
| 检验分析报告 | 认可实验室（如AIRS条件要求） |

## 食品安全标准

### 最大残留限量（MRL）

加拿大MRL框架依据**《食品和药品条例》(FDR)**和**《有害生物控制产品法》(PCPA)**运作：

#### 兽药MRL

- **FDR，第15部分** — 食品中兽药最大残留限量
- **兽药MRL清单**：[canada.ca/en/health-canada/services/drugs-health-products/veterinary-drugs/maximum-residue-limits-mrls](https://www.canada.ca/en/health-canada/services/drugs-health-products/veterinary-drugs/maximum-residue-limits-mrls.html)
- **蛋品关键限值**：

| 物质 | MRL (mg/kg) | 备注 |
|------|-------------|------|
| 金霉素 | 0.4 | 蛋类 |
| 土霉素 | 0.2 | 蛋类 |
| 磺胺二甲氧嘧啶 | 0.1 | 蛋类 |
| 伊维菌素 | 不允许 | 蛋类未建立MRL |
| 氟喹诺酮类 | 不允许 | 禁止用于产蛋家禽 |

#### 农药MRL

- **《有害生物控制产品法》(PCPA)** 和 **FDR，第15部分，表III**
- **加拿大卫生部农药MRL数据库**：[canada.ca/en/health-canada/services/consumer-product-safety/pesticides-pest-management/public/protecting-your-health-environment/pesticides-food/maximum-residue-limits-pesticides](https://www.canada.ca/en/health-canada/services/consumer-product-safety/pesticides-pest-management/public/protecting-your-health-environment/pesticides-food/maximum-residue-limits-pesticides.html)
- 默认MRL：未专门列出的物质为**0.1 ppm**（通用MRL）

### 污染物限值

| 污染物 | 限值 | 法规依据 |
|-------|------|---------|
| 铅 | 0.20 mg/kg | FDR，第15部分 |
| 镉 | 按食品法典委员会标准 | 加拿大卫生部指南 |
| 汞 | 0.5 mg/kg（总量） | 加拿大卫生部指南 |
| 三聚氰胺 | 2.5 mg/kg（食品） | 加拿大卫生部临时标准 |
| 二噁英/呋喃 | 按食品法典委员会指南 | 加拿大卫生部指南 |

### 微生物标准

| 检测项目 | 要求 |
|---------|------|
| 沙门氏菌 | 25g中不得检出 |
| 单核细胞增生李斯特菌 | 25g中不得检出（即食类） |
| 大肠杆菌 | ≤100 CFU/g（加工蛋品） |
| 需氧菌落计数 | 按CFIA指南 |
| 葡萄球菌肠毒素 | 不得检出 |

参考：[CFIA微生物标准与指南](https://inspection.canada.ca/food-safety-for-industry/food-chemistry-and-microbiology/food-safety-testing-bulletins-and-guidelines/eng/1471384838498/1471384839038)

## 标签要求

进口至加拿大的蛋品须符合**SFCR**、**《食品和药品条例》**和**《消费者包装和标签法》**的标签要求：

| 要求 | 详情 |
|------|------|
| **语言** | **英语和法语**（两种官方语言均为强制） |
| **产品名称** | FDR规定的通用名称（如"dried whole egg"/"œuf entier en poudre"） |
| **配料表** | 按重量递减排列；优先过敏原按规定格式标示 |
| **净含量** | 公制单位（克或千克） |
| **日期标示** | "最佳食用日期"+ 储存说明 |
| **进口商** | 加拿大境内名称和主要营业地址 |
| **原产国** | 强制标示："Product of China"/"Produit de Chine"或同等表述 |
| **营养成分表** | 强制 — 按SFCR和FDR，B部分，第1分部 |
| **优先过敏原** | 蛋类为**优先过敏原** — 即使产品本身为蛋品，仍须声明；交叉污染声明 |
| **字体大小** | 基于主展示面面积的最低高度要求 |

### 双语标签

- 所有强制标签元素均须**英语和法语**双语标示
- 仅特定特殊食品可豁免；蛋品**不**符合豁免条件
- 参考：[CFIA食品标签要求](https://inspection.canada.ca/food-labels/labelling/eng/1299879892810/1299879939872)

## 关税与贸易

### 供给管理与TRQ

加拿大蛋品行业实行供给管理制度，**关税配额（TRQ）**控制进口量：

| 类别 | 配额内关税 | 配额外关税 | 备注 |
|------|----------|----------|------|
| 加工蛋品（干燥、液态、冷冻） | 0–3% | ~15.8–17.6% | 按HS编码不同而异 |
| 壳蛋 | 受TRQ限制 | 最高238.5% | 高度受限 |

- **CBSA关税表**：[cbsa-asfc.gc.ca/trade-commerce/tariff-tarif](https://www.cbsa-asfc.gc.ca/trade-commerce/tariff-tarif/2025/html/tblmod-eng.html)
- **全球事务部 — TRQ管理**：[international.gc.ca](https://www.international.gc.ca/trade-commerce/controls-controles/notices-avis.aspx?lang=eng)
- TRQ配额可能需要从全球事务部获取**进口分配**

## 风险提示

- **AIRS资格按产品特定** — 并非所有蛋品类型均可从中国进口；须逐一核实每种特定产品（全蛋粉、蛋白粉、液蛋等）
- **供给管理造成贸易壁垒** — TRQ限制进口量，部分类别的配额外关税极高
- **双语标签为强制要求** — 标签须同时标示英语和法语；不合规将导致边境退回
- **HPAI暂停措施** — 加拿大监控禽流感状况；中国暴发疫情可触发临时进口限制
- **预防控制计划必需** — 加拿大进口商须维护书面PCP；CFIA可进行审计
- **CFIA检查率** — 新产品/新供应商可能面临初期提高的检查率（最高100%）
- **过敏原声明** — 加拿大有严格的优先过敏原标签要求；交叉污染预防声明须遵循规定格式
