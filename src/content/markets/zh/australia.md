## 市场准入概览

澳大利亚对食品进口实行全球最严格的生物安全框架之一。对于来自中国的蛋品，**目前不存在进口途径** — 农业、渔业和林业部（DAFF）尚未完成对中国蛋品的进口风险分析（IRA），而这是市场准入的前提条件。

这是一个**结构性壁垒**，而非临时限制。开放新的进口途径需要正式的IRA流程，通常需要**3-7年**，且目前尚未就中国蛋品启动该流程。

### 关键事实

- **主要立法**：**《2015年生物安全法》** — 取代原有《1908年检疫法》
- **首要把关机构**：DAFF（农业、渔业和林业部） — 管控生物安全进口条件
- **进口条件系统**：**BICON**（生物安全进口条件系统） — 确定可进口产品的权威参考
- **食品标准**：**FSANZ**（澳新食品标准局） — 依据《澳新食品标准法典》制定食品安全标准
- **当前状态**：BICON中不存在中国蛋品的进口条件

## 法律壁垒：进口风险分析（IRA）

### 澳大利亚进口授权运作机制

澳大利亚动物源性食品进口系统通过**生物安全评估框架**运作：

| 层级 | 要求 | 法律依据 |
|------|------|---------|
| **1. 进口风险分析** | DAFF须完成基于科学的风险评估，证明生物安全风险可接受 | [《2015年生物安全法》](https://www.legislation.gov.au/C2015A00061/latest/text)第3章 |
| **2. 进口条件** | 对合格的国家-产品组合在BICON中发布具体条件 | [BICON系统](https://bicon.agriculture.gov.au/) |
| **3. 进口许可** | 进口商获取许可并满足每批货物的所有BICON条件 | 《2015年生物安全法》第3部分 |
| **4. 批准安排** | 部分产品要求进口商在DAFF批准的安排下运营 | 《2015年生物安全法》第7章 |

**中国在第1层即未通过** — 未完成蛋品IRA，因此BICON中不存在相关条件。

### BICON状态

**生物安全进口条件（BICON）**系统是确定进口资格的唯一权威来源：

- **BICON门户**：[bicon.agriculture.gov.au](https://bicon.agriculture.gov.au/)
- 搜索"egg products" → 筛选中国 → **无结果/不允许**
- **批准的蛋源国**（鸡必须在该国孵化、饲养并持续居住）：澳大利亚、比利时、加拿大、丹麦、德国、爱尔兰、意大利、荷兰、新西兰、英国、美国
- **批准的蛋粉生产国**：比利时、加拿大、丹麦、德国、意大利、荷兰、美国
- 生产设施须获得DAFF或加拿大、欧盟/成员国或美国主管机构的批准
- **中国不在上述任何名单中** — 既非批准蛋源国，也非批准生产国
- BICON由DAFF的生物安全植物和动物政策部门维护更新

**最新审查**：**动物生物安全建议2023-A14**（最终报告，2023年11月）审查了现有批准国家的蛋粉进口条件——降低了这些国家的热处理要求，但**未**扩大批准国家名单。
- [BA2023-A14最终报告](https://www.agriculture.gov.au/biosecurity-trade/policy/risk-analysis/memos/ba2023-a14)

### IRA流程要求

要使中国获得向澳大利亚出口蛋品的市场准入，需完成以下流程：

#### 第1步：正式申请

中国主管机构（GACC）须就特定产品类别（如干蛋品、液态蛋品）向DAFF提交正式的市场准入申请。

#### 第2步：进口风险分析

DAFF进行全面的科学风险分析，涵盖：

- **病虫害风险** — 禽流感（HPAI/LPAI）、新城疫、沙门氏菌及其他OIE列名疾病
- **食品安全风险** — 化学残留、污染物、微生物危害
- **加工有效性** — 加工处理（巴氏杀菌、喷雾干燥等）能否充分降低生物安全风险
- **国家兽医体系** — 动物健康监测、疾病控制和残留监控的有效性

IRA遵循DAFF的**进口风险分析手册**：[agriculture.gov.au/biosecurity-trade/policy/risk-analysis](https://www.agriculture.gov.au/biosecurity-trade/policy/risk-analysis)

#### 第3步：利益相关方咨询

- IRA报告草案公开征求意见（最少60天）
- 审查利益相关方意见
- 发布临时和最终IRA报告
- 澳大利亚行业团体（如Australian Eggs、NFF）可能提出反对

#### 第4步：最终决定

- DAFF生物安全主管作出最终决定
- 如获批准，在BICON中发布进口条件
- 之后可申请个别进口许可

**时间**：完整IRA流程从启动到最终决定通常需要**3-7年**。部分IRA历时超过十年。

## 食品安全标准（FSANZ）

如最终获得市场准入，蛋品须符合FSANZ管理的**《澳新食品标准法典》**：

### 标准2.2.2 — 蛋品

**食品标准法典第2.2.2号标准**规定蛋品的成分和加工要求：

- 将"蛋品"定义为经加工（如干燥、巴氏杀菌、冷冻）的蛋源食品
- 要求加工处理足以灭活致病微生物
- 规定最低巴氏杀菌温度/时间参数

全文：[legislation.gov.au — Standard 2.2.2](https://www.legislation.gov.au/F2015L00395/latest/text)

### MRL — 标准1.4.2

**标准1.4.2** — 最大残留限量，规定农药和兽药MRL：

| 类别 | 标准 | 参考 |
|------|------|------|
| 农药MRL | 标准1.4.2，附表20 | [FSANZ MRL数据库](https://www.foodstandards.gov.au/consumer/chemicals/maxresidue) |
| 兽药MRL | 标准1.4.2，附表20 | 与APVMA确定值一致 |
| 污染物 | 标准1.4.1 | 污染物和天然毒素最高限量 |

- **APVMA**（澳大利亚农药和兽药管理局）负责MRL评估
- **APVMA MRL门户**：[apvma.gov.au/node/10806](https://apvma.gov.au/node/10806)

### 蛋品关键MRL

| 物质 | 澳大利亚MRL (mg/kg) | 备注 |
|------|---------------------|------|
| 氟虫腈 | 0.02 | 蛋类 — 非常低的容许值 |
| 毒死蜱 | 0.01 | 蛋类 — 接近检出限 |
| 氟喹诺酮类 | 不允许 | 蛋类未建立MRL |

## 标签要求

依据**《澳新食品标准法典》（标准1.2.1–1.2.11）**：

| 要求 | 详情 |
|------|------|
| **语言** | **英语**（强制） |
| **产品名称** | 法典规定的名称或食品描述 |
| **配料表** | 按重量递减排列 |
| **日期标示** | "最佳食用日期"或"食用期限" |
| **储存条件** | 如需特定条件 |
| **批次标识** | 强制，用于召回 |
| **营养信息面板（NIP）** | 能量、蛋白质、脂肪（饱和/总量）、碳水化合物（糖/总量）、钠 — 每份和每100g |
| **原产国** | 依据**《2016年原产国食品标签信息标准》**强制标示 — 需原产国声明和显示澳大利亚成分百分比的条形图 |
| **过敏原声明** | 蛋类为**强制过敏原** — 须按标准1.2.3以粗体或规定格式声明 |
| **制造商/进口商** | 澳大利亚境内供应商名称和地址 |

### 原产国标签（CoOL）

澳大利亚有特别严格的原产国标签要求：

- **《2016年原产国食品标签信息标准》**要求：
  - 文字声明（如"Made in China"或"Product of China"）
  - 显示澳大利亚成分百分比的**条形图**（完全进口产品为0%）
  - 进口产品不需要袋鼠标识
- 参考：[business.gov.au — 原产国食品标签](https://www.business.gov.au/products-and-services/selling-products/country-of-origin-food-labelling)

## 风险提示

- **勿将澳大利亚出口作为近期策略** — 结构性壁垒（未完成IRA）使市场准入在1-5年内不太可能实现
- **无IRA启动迹象** — 没有公开信息表明中国蛋品的IRA已被申请或启动
- **澳大利亚生物安全文化极其保守** — 2001年后尤其是2020年（COVID）后，对新增动物产品进口的政治和公众阻力很强
- **HPAI是关键关注点** — 澳大利亚认为自身基本不受HPAI影响；来自HPAI受影响国家的进口面临更严格审查
- **澳大利亚蛋品行业游说** — Australian Eggs（行业组织）历来反对扩大蛋品进口；他们参与IRA咨询流程
- **即使IRA成功，合规门槛极高** — 部分物质的FSANZ MRL（如氟虫腈0.02 mg/kg）极为严格

## 战略考量

- 关注DAFF的IRA公告和生物安全政策更新
- 将建设符合澳大利亚食品标准（FSANZ法典）的合规能力作为长期投资 — 该标准同样适用于新西兰
- 将资源集中在可进入的市场，同时关注澳大利亚动态
- 如寻求澳大利亚市场准入，需协调GACC提出正式的政府间市场准入请求
- 《中澳自贸协定》(ChAFTA)涵盖关税减让，但**不**覆盖生物安全要求
