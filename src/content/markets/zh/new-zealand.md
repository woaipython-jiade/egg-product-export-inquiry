## 市场准入概览

新西兰通过**初级产业部（MPI）**监管蛋品进口，该部门集食品安全、生物安全和动物健康职能于一体。**《蛋品2023年进口健康标准》**（2023年4月26日生效）管辖所有蛋品进口——但要求出口国主管机构与MPI之间存在**经协商的国家特定兽医证书**。

**中国与MPI之间不存在蛋品兽医证书。** 没有该证书，中国蛋品**无法合法进口**至新西兰。

这是一个**结构性壁垒**，而非临时限制。开放进口途径需要正式的政府间谈判、等效性评估和IHS修订。

### 关键事实

- **主要立法**：**《1993年生物安全法》**（IHS依据第24A条签发）、**《2014年食品法》**、**《1999年动物产品法》**
- **首要把关机构**：**MPI**（初级产业部） — 发布IHS、管控边境生物安全
- **当前IHS**：**蛋品2023** — 2023年4月26日生效，2023年10月26日撤销此前2019版IHS
- **食品标准**：**FSANZ**（澳新食品标准局） — 联合食品标准法典适用于新西兰
- **WTO通报**：SPS通报NZL/703

### 持有协商兽医证书的国家

目前仅少数国家持有蛋品协商兽医证书：

| 国家/地区 | 证书类型 |
|----------|---------|
| **美国** | 国家特定兽医证书（货架稳定型喷雾干燥蛋粉/蛋晶） |
| **欧盟** | 通过EU TRACES系统（覆盖欧盟成员国） |
| **丹麦** | 国家特定兽医证书 |
| **荷兰** | 国家特定兽医证书 |
| **加拿大** | 国家特定兽医证书 |

**中国不在此名单中。** MPI与GACC之间不存在蛋品协商证书。

## 法律壁垒：兽医证书要求

### 新西兰进口授权运作机制

IHS 2023建立了**基于证书的准入体系**：

| 层级 | 要求 | 法律依据 |
|------|------|---------|
| **1. 协商兽医证书** | 出口国主管机构须与MPI协商并获得MPI接受的特定产品兽医证书 | [蛋品IHS 2023](https://www.mpi.govt.nz/dmsdocument/56659-Egg-Products-Import-Health-Standard-2023/)，《1993年生物安全法》第24A条 |
| **2. IHS合规** | 产品须满足IHS中的所有生物安全和食品安全条件 | 蛋品IHS 2023 |
| **3. 边境清关** | MPI检查文件并可能进行实物检查 | 《1993年生物安全法》 |

**中国在第1层即未通过** — 不存在协商兽医证书，第2、3层无从谈起。

### IHS 2023关键要求

蛋品2023 IHS规定：

- **国家资格**：仅持有协商兽医证书的国家可出口（IHS指南文件列出这些国家）
- **原产国**：若蛋品原产国与出口国不同，原产国也须满足IHS第1.5条要求——即通过第三国转出口**不能**绕过壁垒
- **加工要求**：蛋品须经热处理/加工（巴氏杀菌、喷雾干燥）至规定参数
- **无疫病**：来自无应报告疾病的家禽群
- **微生物合规**：须符合FSANZ附表27的沙门氏菌限值

**IHS文件**：[蛋品进口健康标准2023 (PDF)](https://www.mpi.govt.nz/dmsdocument/56659-Egg-Products-Import-Health-Standard-2023/)
**指南文件**：[蛋品IHS指南文件](https://www.mpi.govt.nz/dmsdocument/27249-Egg-products-Import-Health-Standard-Guidance-Document)

### 生蛋禁止进口

**生蛋产品和鲜蛋不可**从任何国家进口至新西兰。仅来自批准国家的**加工蛋品**（巴氏杀菌液蛋、蛋粉、干蛋）可进口。

## 改变准入状态所需条件

要使中国获得新西兰蛋品市场准入：

### 第1步：政府间申请

中国主管机构（GACC）须正式联系MPI，启动蛋品国家特定兽医证书的协商。

### 第2步：等效性评估

MPI将评估中国蛋品食品安全体系，包括：

- 家禽生产中的沙门氏菌控制计划
- 兽药残留监控
- 加工标准和工厂卫生
- 官方认证体系和主管机构能力
- 疾病监测（尤其是HPAI和新城疫）

### 第3步：证书协商

MPI和GACC将协商国家特定兽医证书的具体格式和内容，涵盖：

- 动物健康认证
- 食品安全认证
- 加工认证
- 官方机构背书

### 第4步：IHS修订

指南文件将更新以纳入中国的新兽医证书。可能需要WTO SPS通报。

**时间**：这是一个**多年期流程**，且目前**无公开迹象**表明谈判正在进行。可联系MPI **animal.imports@mpi.govt.nz** 了解最新状态。

## 食品安全标准（FSANZ法典）

如最终获得市场准入，蛋品须符合**《澳新食品标准法典》**：

### 标准2.2.2 — 蛋品

- 将"蛋品"定义为经加工的蛋源食品
- 要求加工处理能灭活致病微生物
- 规定成分和加工要求
- **FSANZ提案P1060**（2025年9月批准）强化了标准4.2.5和2.2.2，增加了肠炎沙门氏菌监测和追溯要求

全文：[legislation.gov.au — Standard 2.2.2](https://www.legislation.gov.au/F2015L00395/latest/text)

### MRL — 标准1.4.2

| 类别 | 标准 | 参考 |
|------|------|------|
| 农药MRL | 标准1.4.2，附表20 | [FSANZ MRL数据库](https://www.foodstandards.gov.au/consumer/chemicals/maxresidue) |
| 兽药MRL | 标准1.4.2，附表20 | 联合FSANZ/APVMA |
| 污染物 | 标准1.4.1 | 污染物最高限量 |

新西兰还通过MPI内部的**ACVM小组**参考自身的**农业化合物和兽药（ACVM）**法规：

- **ACVM注册**：[mpi.govt.nz/agriculture/agricultural-compounds-and-veterinary-medicines](https://www.mpi.govt.nz/agriculture/agricultural-compounds-and-veterinary-medicines/)
- 部分物质的MRL可能与澳大利亚略有差异

### 蛋品关键MRL

| 物质 | MRL (mg/kg) | 备注 |
|------|-------------|------|
| 氟虫腈 | 0.02 | 非常严格 — 与澳大利亚一致 |
| 毒死蜱 | 0.01 | 接近检出限 |
| 氟喹诺酮类 | 不允许 | 蛋类无MRL |
| 四环素类 | 0.2–0.4 | 按FSANZ附表20 |

### 污染物限值（标准1.4.1）

| 污染物 | 限值 (mg/kg) | 产品 |
|-------|-------------|------|
| 铅 | 0.5 | 蛋类 |
| 镉 | 0.05 | 蛋类 |
| 汞 | 0.03 | 蛋类 |

### 微生物标准（附表27）

| 检测项目 | 要求 |
|---------|------|
| 沙门氏菌 | 25g中不得检出（附表27限值） |
| 单核细胞增生李斯特菌 | 25g中不得检出（即食类） |
| 大肠杆菌 | 按FSANZ/MPI指南 |
| 需氧菌落计数 | 按产品类别 |

## 标签要求

标签遵循**《澳新食品标准法典》**，另有新西兰特定要求：

| 要求 | 详情 |
|------|------|
| **语言** | **英语**（强制） |
| **产品名称** | 法典规定的名称或描述性名称 |
| **配料表** | 按重量递减排列 |
| **日期标示** | "最佳食用日期"或"食用期限" |
| **储存条件** | 如需特定条件 |
| **批次标识** | 强制，用于追溯 |
| **营养信息面板（NIP）** | 能量、蛋白质、脂肪（饱和/总量）、碳水化合物（糖/总量）、钠 — 每份和每100g |
| **原产国** | 进口食品强制标示（《1986年公平贸易法》） |
| **过敏原声明** | 蛋类为**强制过敏原** — 须按标准1.2.3声明。新过敏原标签要求2024年2月25日生效，过渡期至2026年2月25日 |
| **制造商/进口商** | 新西兰境内供应商名称和地址 |

### 新西兰特有标签说明

- 新西兰**不**要求澳大利亚式的原产国条形图/袋鼠标识
- 简单的原产国文字声明即可（如"Product of China"）
- **《1986年公平贸易法》**适用于所有食品标签声明 — 禁止误导或欺骗性标签

参考：[MPI — 食品和饮料标签规则](https://www.mpi.govt.nz/food-business/labelling-composition-food-drinks/food-and-drink-labelling-and-composition-rules)

### 新中自贸协定

**新西兰-中国自由贸易协定**（2008年生效）是中国与发达国家间第一个综合性FTA：

- 大多数蛋品税号已在FTA日程下降至**0%**
- 适用原产地规则要求 — 产品须符合FTA原产地规则
- **FTA门户**：[mfat.govt.nz/en/trade/free-trade-agreements/free-trade-agreements-in-force/nz-china-free-trade-agreement](https://www.mfat.govt.nz/en/trade/free-trade-agreements/free-trade-agreements-in-force/nz-china-free-trade-agreement/)
- **关税优惠不覆盖生物安全/IHS要求** — 即使关税为0%，产品仍须持有批准的兽医证书

## 风险提示

- **勿将新西兰出口作为近期策略** — MPI与GACC之间不存在蛋品兽医证书；市场准入被结构性阻断
- **无谈判进展迹象** — 没有公开信息表明中国已启动与MPI的证书协商流程
- **转出口途径被阻断** — IHS第1.5条要求原产国也须满足要求，因此通过批准第三国转出中国蛋品**不可行**
- **HPAI是关键障碍** — 新西兰无HPAI；中国的疾病状况将是任何等效性评估的重大障碍
- **新中自贸协定无法帮助** — 虽然关税可能为0%，但FTA明确**不**覆盖生物安全要求
- **FSANZ MRL非常严格** — 部分物质（如氟虫腈0.02 mg/kg）处于或接近检出限
- **新过敏原标签规则** — 标准1.2.3变更2024年2月生效，过渡期至2026年2月

## 战略考量

- 关注MPI IHS更新和新兽医证书公告
- 将建设符合FSANZ标准的合规能力作为长期投资 — 该标准同时适用于澳大利亚和新西兰
- 将资源集中在可进入的市场，同时关注新西兰动态
- 如寻求新西兰市场准入，需协调GACC向MPI提出正式的政府间谈判请求
- 联系MPI **animal.imports@mpi.govt.nz** 了解最新资格状态
