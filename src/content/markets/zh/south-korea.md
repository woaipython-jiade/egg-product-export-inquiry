## 市场准入概览

韩国是中国蛋品的潜在重要市场，但准入受到食品安全和动物检疫双重**严格限制**。两个机构共同管控进口：

- **食品药品安全部（MFDS / 식품의약품안전처）** — 食品安全标准、进口检查、境外设施注册
- **农林畜产检疫本部（APQA / 농림축산검역본부）** — 动物检疫、HPAI管控、兽医证书

准入状态为"受限" — 法律贸易框架存在，但**中国禽类和蛋品因HPAI相关暂停**是阻碍活跃贸易的首要壁垒。

### 关键事实

- **HPAI暂停**：APQA对有活跃HPAI暴发国家的禽类/蛋品实施进口限制 — **中国已多次受到暂停影响**
- **境外设施注册**：依据**《进口食品安全管理特别法》（수입식품안전관리특별법）**，境外生产商须向MFDS注册
- **韩语标签**：依据**《食品等标示·广告法》（식품 등의 표시·광고에 관한 법률）**，所有进口食品须使用韩语标签
- **中韩FTA**：2015年12月生效，但蛋品（HS 0408）因农业敏感性获得的关税减让有限
- 韩国是加工蛋品（特别是蛋粉和液蛋，用于食品制造）的**净进口国**

## 动物检疫（APQA）

### HPAI进口管控

APQA依据**《家畜传染病预防法》（가축전염병예방법）**对来自HPAI暴发国的进口实施严格管控：

- **机制**：出口国确认HPAI时，APQA暂停该国或受影响地区的禽类和蛋品进口
- **范围**：涵盖壳蛋、液蛋、冷冻蛋，加工蛋制品视热处理情况可能也在范围内
- **当前状态**：中国经历过多次HPAI暴发 — **发货前务必向APQA确认当前暂停状态**
- **APQA进口检疫要求**：[https://www.qia.go.kr/animal/quarantine/ani_livestock_import.jsp](https://www.qia.go.kr/animal/quarantine/ani_livestock_import.jsp)

### 兽医卫生证书要求

每批货物须附带GACC出具的**官方兽医卫生证书**，证明：

1. 原产国/地区**无HPAI和新城疫**（按WOAH标准）
2. 产品来自官方兽医监管下的家禽群
3. 产品在政府卫生管控下的设施中加工
4. 热处理参数（加工产品）已记录并经认证
5. 产品兽药残留不超过韩国MRL限量

### 热处理产品豁免

经过充分热处理灭活HPAI病毒的加工蛋制品（蛋粉、巴氏杀菌液蛋）可能获得HPAI相关暂停的豁免：

- **OIE/WOAH陆生动物卫生法典第10.4章**提供安全商品指引
- 中心温度达到**70°C持续3.5秒**（巴氏杀菌）或等效热处理
- APQA逐案判定 — 发运前请咨询

**来源**：[APQA动物检疫（英文）](https://www.qia.go.kr/english/html/Animal_livestock/ani_livestock_import-E.jsp)

## 食品安全与进口注册（MFDS）

### 进口食品安全管理特别法

**《进口食品安全管理特别法》（수입식품안전관리특별법）**是规范食品进口的主要法规。主要要求：

### 境外设施注册

| 要求 | 详情 |
|------|------|
| 法律依据 | 《进口食品安全管理特别法》第5条 |
| 系统 | **进口食品信息系统（IFIS）** — [https://impfood.mfds.go.kr](https://impfood.mfds.go.kr) |
| 注册主体 | **境外生产商**（或通过授权韩国代理人） |
| 所需材料 | 设施信息、产品类型、生产工艺、卫生控制文件 |
| 有效期 | 注册须维护和更新；定期审查 |
| 后果 | 未注册设施的产品**无法通过韩国海关** |

### 进口检查流程

所有进口食品须在指定口岸接受MFDS进口检查：

| 步骤 | 流程 |
|------|------|
| 1 | 韩国进口商向MFDS地方分局提交**进口申报** |
| 2 | MFDS进行**文件审查**（产品信息、证书、标签） |
| 3 | 检查判定：感官、物理、化学或微生物检测 |
| 4 | **首次进口**：所有参数强制实验室检测 |
| 5 | 后续进口：基于风险的检查（随机抽样） |
| 6 | 结果：合格→海关放行；不合格→退运、销毁或重新加工 |

### 检查递进

- **首次进口**：所有参数100%检测
- **合规历史良好**：降至随机抽样（约10–20%货物）
- **发现违规**：升级为**全面检查** — 每批货物检测
- **反复违规**：可能导致特定产品/生产商**进口暂停**
- MFDS在线公布**不合规进口结果** — [MFDS进口食品检查结果](https://www.foodsafetykorea.go.kr/portal/board/boardDetail.do)

**来源**：[MFDS进口食品安全（韩文）](https://www.mfds.go.kr/wpge/m_659/de010602l001.do) | [MFDS英文门户](https://www.mfds.go.kr/eng/index.do)

## 食品安全标准（韩国食品公典）

### 韩国食品公典（식품공전）

由MFDS维护的韩国食品公典为包括蛋品在内的食品设定标准：

- **完整食品公典**：[https://www.foodsafetykorea.go.kr/foodcode/](https://www.foodsafetykorea.go.kr/foodcode/)

### MRL体系（残留标准）

韩国运行自有的兽药和农药残留限量体系：

| 类别 | 框架 |
|------|------|
| **兽药MRL** | 由MFDS依据《畜产品卫生管理法》管理 |
| **农药MRL** | 2019年1月起实施肯定列表制度（PLS）— 与日本体系类似 |
| **默认MRL** | 未建立MRL的物质默认**0.01 ppm**（PLS下） |

### 蛋品关键MRL

| 物质 | 韩国蛋中MRL | 备注 |
|------|------------|------|
| 恩诺沙星（氟喹诺酮类） | 0.01 ppm（PLS默认） | 历史问题物质 — 严格执法 |
| 氯霉素 | 不得检出 | 零容忍 |
| 氟虫腈 | 0.02 ppm | 2017年韩国氟虫腈鸡蛋危机后高度敏感 |
| 金刚烷胺 | 不得检出 | 抗病毒药 — 食用动物零容忍 |
| 尼卡巴嗪 | 0.01 ppm（PLS默认） | 抗球虫药 — 须确保停药期 |

## 标签要求

韩国食品标签由MFDS主管的**《食品等标示·广告法》（식품 등의 표시·광고에 관한 법률）**规范。

### 强制标签要素

| 要求 | 详情 |
|------|------|
| 语言 | **韩语（한국어）** — 强制；可附加其他语言 |
| 产品名称 | 须对应食品公典规定的名称 |
| 配料表 | 按重量递减排列；所有食品添加剂须列出 |
| **过敏原声明** | **蛋类（알류/난류）为强制过敏原** — 韩国过敏原声明要求之一 |
| 净重 | 公制单位（g、kg、mL、L） |
| 日期标示 | 유통기한（保质期）或 품질유지기한（最佳食用期） |
| 储存条件 | 温度和方法 |
| 原产国 | "원산지: 중국 (China)" — 所有进口食品强制标注 |
| 进口商名称和地址 | 完整韩国工商登记地址 |
| 营养标签 | 热量、碳水化合物、糖、蛋白质、脂肪、饱和脂肪、反式脂肪、胆固醇、钠 — **9项强制营养素** |
| 条形码 | 零售产品须标注 |

### 过敏原声明

韩国强制要求以下过敏原标签（包括蛋类）：

**强制过敏原**：蛋类、乳、荞麦、花生、大豆、小麦、鲭鱼、蟹、虾、猪肉、桃、番茄、亚硫酸盐、核桃、鸡肉、牛肉、鱿鱼、贝类（含牡蛎、鲍鱼、贻贝）、松子

蛋品须醒目声明"알류(계란) 함유"（含蛋类）。

**来源**：[MFDS食品标签标准](https://www.mfds.go.kr/wpge/m_658/de010601l001.do)

## 关税与贸易（中韩FTA）

### HS 0408关税结构

| HS编码 | 描述 | 基础MFN税率 | 中韩FTA |
|--------|------|------------|---------|
| 0408.11 | 干燥蛋黄 | 8% | 有限减让 — 农业敏感性排除 |
| 0408.19 | 其他蛋黄（液态/冷冻） | 8% | 有限减让 |
| 0408.91 | 其他干燥蛋（全蛋/蛋白） | 8% | 有限减让 |
| 0408.99 | 其他去壳蛋 | 8% | 有限减让 |

### FTA备注

- **中韩FTA**（2015年12月生效）对许多产品提供关税减让，但**包括蛋品在内的农产品基本被排除**或纳入长期过渡类别（10–20年逐步取消）
- **关税查询**：[韩国关税厅 — 关税信息](https://unipass.customs.go.kr/clip/index.do)
- **增值税**：进口货物10%（按CIF+关税计算）

## 风险提示

- **HPAI暂停是首要壁垒** — 中国反复发生HPAI暴发导致禽类/蛋品进口暂停；任何规划前须向APQA确认当前状态
- **2017年氟虫腈鸡蛋丑闻**是韩国重大国内危机 — 当局对蛋品中农药残留极度敏感；预计执法严格
- **肯定列表制度（PLS）**与日本体系类似 — 未建立MRL的任何物质默认**0.01 ppm**，实际等同零容忍
- **首次进口面临100%检查** — 须预留实验室检测的额外时间和费用
- **MFDS设施注册**是前提条件 — 未注册生产商的产品将在海关被拒绝
- **韩语标签错误**是进口被拒的常见原因 — 请聘请合格的韩国法规顾问审核标签
- **韩国公布所有不合规进口结果** — 违规公开可见，损害全市场的商业声誉
- **农业敏感性** — 蛋品在韩国贸易政策中属政治敏感产品；FTA减让极为有限

## 行动清单

- [ ] **查核APQA HPAI暂停状态**（中国禽类/蛋品） — [APQA网站](https://www.qia.go.kr)
- [ ] 确认海关总署注册（第248/249号令）涵盖对韩出口
- [ ] 通过[IFIS系统](https://impfood.mfds.go.kr)在MFDS注册生产设施
- [ ] 确定您的热处理产品是否符合HPAI豁免条件（咨询APQA）
- [ ] 按**韩国MRL**检测 — 特别是氟虫腈、氟喹诺酮类及所有PLS涵盖物质
- [ ] 对无特定韩国MRL的物质按**0.01 ppm默认值**进行合规检测
- [ ] 联系有MFDS进口申报经验的韩国进口商
- [ ] 准备**韩语标签**，含所有强制要素（9项营养素、过敏原声明）
- [ ] 声明蛋过敏原："알류(계란) 함유"
- [ ] 从GACC获取含HPAI/ND清净证明的兽医卫生证书
- [ ] 查核FTA关税分类 — [KCS UniPass](https://unipass.customs.go.kr/clip/index.do)
- [ ] 为首次进口检查延误预留3–4周缓冲时间
- [ ] 关注MFDS中国食品进口检查结果
