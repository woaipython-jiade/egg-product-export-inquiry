## 市场准入概览

香港和澳门是中国蛋品最易进入的出口目的地。两个特别行政区均有明确的监管框架。

**香港**通过**两个独立法律体系**监管蛋品进口：
- **《第132AK章》** — 进口野味、肉类、家禽及蛋类规例（进口许可和卫生证书）
- **《第612章》** — 食物安全条例（进口商注册和档案保存）

**澳门**由**市政署（IAM）**根据**第5/2013号法律**（食品安全法）监管食品进口，要求进口许可和强制边境检验。

### 主要优势

- **无配额限制** — 中国蛋品进口无数量限制
- **地理优势** — 经陆路口岸可当天送达
- **成熟监管框架** — 要求已公开发布
- **庞大消费市场** — 香港约90%的食品依赖进口
- **CFS 2024年监测**：约66,900个样本检测，**99.8%合格率**

## 香港：两步授权制度

### 第一步：食品进口商注册（第612章）

所有食品进口商须根据**《食物安全条例》（第612章）**注册：

| 项目 | 详情 |
|------|------|
| 费用 | **HK$195**（新注册）；HK$180（续期） |
| 有效期 | **3年** |
| 申请地点 | 食物进口商/分销商登记及进口签证办事处，湾仔皇后大道东258号1楼119室 |
| 在线 | 食物商资料系统（FTP） |
| 未注册罚则 | 最高**HK$50,000**罚款及**6个月**监禁 |
| 未保存记录罚则 | 最高**HK$10,000**罚款及**3个月**监禁（第21-24条） |

- 来源：[CFS注册申请](https://www.cfs.gov.hk/english/foodsafetyordinance/FSO_application.html)

### 第二步：蛋类进口许可（第132AK章）

此许可与上述进口商注册**分开**且为**额外要求**。

| 项目 | 详情 |
|------|------|
| 申请表格 | **FEHB 295** — "申请进口蛋类许可证" |
| 费用 | **免费** |
| 处理时间 | 如符合要求可在**4个工作日**内批出 |
| 有效期 | 自签发日起**6个月** |
| 提交至 | 食物安全中心食物进出口组，香港金钟道66号金钟道政府合署43楼 |
| 电邮 | fsc@fehd.gov.hk |
| 电话 | 2867 5577 |
| 传真 | 2521 4784 |
| 不合规罚则 | 最高**HK$50,000**罚款及**6个月**监禁 |

**每次申请须提供：**
- 注明拟进口蛋类的种类和数量
- 注明原产地（须经食环署署长认可）
- 认可原产地签发机构出具的卫生证书

- 来源：[CFS蛋类进口许可申请指南](https://www.cfs.gov.hk/english/import/Guide_to_Application_for_Permission_to_Import_Eggs.html)

### 卫生证书

每批货物须附有中国海关当局（GACC/地方海关）签发的卫生证书，证明产品适合人类食用。

### 入境口岸

| 入境口岸 | 运输方式 |
|---------|---------|
| **文锦渡食物管制办事处（MKTFCO）** | 陆路——处理陆路大陆食品货物的唯一办事处 |
| **香港国际机场（HKIA）** | 空运 |
| **港珠澳大桥香港口岸** | 陆路（大桥） |
| 指定冷藏仓检验站 | 海运 |

## 香港：食品安全标准

### 微生物标准

依据[CFS食品微生物含量指引(PDF)](https://www.cfs.gov.hk/english/food_leg/files/food_leg_Microbiological_Guidelines_for_Food_e.pdf)——2014年8月14日生效：

| 检测项目 | 限值 | 判定 |
|---------|------|------|
| 沙门氏菌 | **25g中不得检出** | 如检出：判定为"可能对健康有害/不适合食用" |
| 单增李斯特菌 | 25g中不得检出 | 即食产品 |
| 大肠杆菌（普通） | <20 CFU/g | 满意 |
| 需氧菌落计数 | <10⁴ CFU/g | 满意 |

### 化学污染物及残留

**有害物质（第132AF章）**：

| 物质 | 限值 | 备注 |
|------|------|------|
| 三聚氰胺 | **2.5 mg/kg**（一般食品）；**1 mg/kg**（婴幼儿食品、孕妇/哺乳期妇女食品） | 2021年修订 |
| 苏丹红（I–IV号） | **不得检出** | CFS定向监测 |
| 真菌毒素（黄曲霉毒素、脱氧雪腐镰刀菌烯醇、展青霉素） | 按第132AF章2021年修订附表 | |
| 苯并[a]芘 | 按第132AF章 | |
| 3-MCPD、缩水甘油酯 | 按第132AF章2021年修订 | |

**重金属（第132V章）**——2025年9月修订：

| 污染物 | 限值 | 备注 |
|-------|------|------|
| 铅 | **0.5 mg/kg** | 附表第2部分。完整表格：[第132V章](https://www.elegislation.gov.hk/hk/cap132V) |
| 其他金属 | 按第132V章附表 | 镉、汞、砷限值见第2部分 |

**兽药残留**：按食品法典委员会/中国GB 31650 MRL。CFS进行风险导向监测。

**农药残留（第132CM章）**：MRL和EMRL见附表1。完整表格：[第132CM章](https://www.elegislation.gov.hk/hk/cap132CM)

### 标签要求（第132W章）

在港销售的所有预包装蛋制品须标示：

| 要求 | 详情 |
|------|------|
| 语言 | **中文及/或英文**。如使用双语，名称及配料表须以两种语言标示 |
| 产品名称 | 准确描述 |
| 配料表 | 按重量/体积递减排列 |
| 致敏物质声明 | 蛋类为**8种强制申报致敏原**之一 |
| 日期标示 | "此日期前最佳"或"此日期前食用" |
| 营养标签 | **"1+7"制度**——能量加7种营养素 |
| 贮存条件 | 如需要 |
| 制造商/进口商 | 名称和地址 |
| 原产国 | 必须标示 |
| 净重/净含量 | 使用公制单位 |

## 澳门：监管要求

### 管辖法规

| 法规 | 用途 |
|------|------|
| **第5/2013号法律** | 食品安全法（主要食品安全立法） |
| **第487/2016号行政法规** | 入境强制检验——附表三包括蛋类 |
| **第56/94/M号法令** | 预包装及非预包装食品标签 |
| **第13/2016号行政法规** | 食品中真菌毒素最高限量 |

### 监管机构

**市政署（IAM）**（Instituto para os Assuntos Municipais），2019年1月1日成立。IAM**食品安全厅**及其**食品检验处**负责进口检验。

- 门户：[IAM食品安全资讯](https://www.iam.gov.mo/foodsafety/e/index)

### 进口程序

1. **进口许可申请**：在货物到达前**至少3个工作日**提交IAM
2. **提前通知**：在进口前**1个工作日**在IAM完成相关手续
3. **检疫检验预约**：须向食品安全厅预约
4. **所需文件**：
   - GACC/地方海关签发的卫生证书原件
   - 原产地证书
   - 产品检测报告（如IAM要求）
   - 商业发票及装箱单

- 来源：[IAM检验检疫](https://www.iam.gov.mo/foodsafety/e/quarantine/detail/7570c4ae-729c-42fa-9c79-f5a97f878e78)

### 标签要求（第56/94/M号法令）

| 要求 | 详情 |
|------|------|
| 语言 | **葡文及/或中文**（实践中中文标签可被接受） |
| 产品名称 | 必须标示 |
| 配料表 | 必须标示 |
| 净含量 | 必须标示 |
| 日期标示 | 生产日期和保质期 |
| 贮存条件 | 必须标示 |
| 制造商/进口商 | 名称和地址 |
| 原产国 | 必须标示 |

## 风险提示

- **三聚氰胺检测**仍是所有中国大陆蛋品的常规检查项目——2008年事件遗留影响，至今为CFS标准程序
- **苏丹红筛查**被纳入CFS蛋品定向监测——确保生产链与苏丹红无接触
- **第132V章修订（2025年9月）**——更新了金属杂质含量限值；须核实是否符合新附表
- **CFS每月公布食品监测结果**——不合格产品会被公开点名，损害贸易关系
- **澳门IAM**在食品安全事件期间可能实施额外要求——关注[IAM公告](https://www.iam.gov.mo/foodsafety/e/index)
- **高致病性禽流感（HPAI）**在中国大陆暴发可触发对受影响省份的临时暂停
- **加工蛋制品适用范围**：第132AK章对"蛋"的定义涵盖"禽蛋的任何可食部分"，但明确排除"全熟蛋"和"复合食品配料中的蛋"。对于独立产品的蛋粉、液蛋和冷冻蛋——建议致电CFS确认分类：**2867 5577**或**fsc@fehd.gov.hk**

## 行动清单

- [ ] 确认海关总署注册有效（第249号令）
- [ ] 确保香港进口商已根据**第612章**注册（HK$195/3年）
- [ ] 使用**表格FEHB 295**申请进口许可（免费，有效期6个月）
- [ ] 为每批货物获取卫生证书
- [ ] 检测三聚氰胺（<2.5 mg/kg）和苏丹红（不得检出）
- [ ] 核实重金属是否符合**第132V章**（2025年9月修订）
- [ ] 按CFS微生物指引检测（沙门氏菌25g不得检出）
- [ ] 准备符合第132W章的中英文双语标签
- [ ] 安排经文锦渡（陆路）、香港国际机场（空运）或港珠澳大桥口岸（大桥）入境
- [ ] 澳门方面：进口商提交IAM许可≥3个工作日 + 提前通知≥1个工作日
- [ ] 澳门方面：向IAM食品安全厅预约检疫检验
- [ ] 关注CFS每月监测报告了解执法趋势
