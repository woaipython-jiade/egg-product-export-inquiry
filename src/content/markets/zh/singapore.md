## 市场准入概览

新加坡是东南亚监管最透明、标准最高的食品进口市场之一。**新加坡食品局（SFA）**根据**《食品销售法》（Sale of Food Act 1973）**及其**《食品条例》（Food Regulations）**监管所有食品进口。中国被列为SFA认可/批准/声明/其他来源（ADOS）数据库中蛋品的**认可来源国**。

### 主要特点

- **认可来源地位** — 中国已列入SFA的ADOS数据库蛋品类别
- **两级许可制度** — 需同时持有贸易商执照和逐批进口许可
- **透明要求** — SFA在线公布详细的进口条件
- **高端市场** — 优质产品可获更高价格；约90%食品依赖进口
- **英语文件体系** — 所有文件和标签均使用英语

---

## SFA许可制度：两级体系

### 第一级：贸易商执照

新加坡进口商须首先获得**SFA贸易商执照**方可进口食品：

- **申请途径**：通过SFA在线许可系统 [SFA GoBusiness门户](https://www.sfa.gov.sg/food-import-export)
- **执照类型**："食品进口" — 专门涵盖蛋及蛋制品
- **有效期**：每年须续期
- **要求**：进口商须指定一名合格的食品安全负责人

### 第二级：逐批进口许可

**每批货物**均须通过新加坡**TradeNet系统**申请进口许可：

- **申请途径**：通过TradeNet（新加坡国家贸易申报单一窗口）
- **时间要求**：须在货物**到达新加坡之前**获得许可
- **所需支持文件**：
  - 中国海关当局（GACC）签发的卫生证书
  - 产品检测报告（微生物和化学指标）
  - 原产地证书
  - 商业发票和装箱单

## 查验中国认可状态

在启动出口流程前，请在SFA数据库中确认中国的当前认可状态：

- **ADOS交互式数据库**：在[SFA ADOS数据库](https://www.sfa.gov.sg/tools-and-resources/accreditation-database-for-overseas-sources)中按国家和产品类型搜索 — 选择"China"和"Eggs & Egg Products"
- **批准国家PDF**：下载完整名单 [SFA批准国家/地区（PDF）](https://www.sfa.gov.sg/docs/default-source/food-import-and-export/list_of_approved_countries_regions.pdf)
- **重要**：批准在**两个层级**授予 — 产品类别的国家级批准和单个企业的认可。两者均须确认。
- **注意**：在食品安全事件或疫病暴发期间，认可资格可能被暂停 — 关注[SFA贸易通告](https://www.sfa.gov.sg/news-publications/circulars-and-notices)了解最新动态

## 食品安全标准

SFA根据**《食品条例》**（《食品销售法》附属法例）执行标准：

### 微生物限值

| 检测项目 | 标准 | 法规依据 |
|---------|------|---------|
| 沙门氏菌 | 25g中不得检出 | 《食品条例》附表十一 |
| 大肠杆菌 | 按SFA微生物标准 | 《食品条例》 |
| 需氧菌落计数 | 按产品类别限值 | SFA指南 |

### 化学残留限值

**兽药最大残留限量（MRL）** — 依据《食品条例》**附表十八**：

| 物质类别 | 要求 |
|---------|------|
| 替米考星（Tilmicosin） | 蛋中**不得检出**（零容忍） |
| 氟喹诺酮类（如恩诺沙星） | 蛋中**不得检出** — 历史上中国蛋品被拒的最常见原因 |
| 氯霉素 | **不得检出**（全球零容忍） |
| 其他兽药 | 须符合附表十八或食品法典委员会的MRL |

**重金属** — 依据《食品条例》**附表十**：

| 污染物 | 限值 |
|-------|------|
| 铅 | 0.1 mg/kg（鲜蛋），0.5 mg/kg（加工蛋制品） |
| 镉 | 按附表十限值 |
| 汞 | 按附表十限值 |

**其他污染物**：

| 污染物 | 限值 | 法规依据 |
|-------|------|---------|
| 黄曲霉毒素（总量） | 5 μg/kg | 《食品条例》 |
| 三聚氰胺 | 按食品法典委员会指南 | SFA执法 |
| 苏丹红 | 不得检出 | 《食品条例》 |
| 3-MCPD | 按SFA指南 | 风险评估 |

### 《2025年食品安全与保障法》

新加坡颁布了**《2025年食品安全与保障法》（Food Safety and Security Act 2025）**（分阶段生效），取代《食品销售法》。对进口商的主要变化：
- 增强溯源要求
- 加强SFA执法权力
- 更新食品安全标准
- 进口商应关注SFA公告了解实施时间表

## 标签要求

所有预包装蛋制品须符合SFA标签规定：

| 要求 | 详情 |
|------|------|
| 语言 | **英语**（强制） |
| 产品名称 | 须准确描述产品 |
| 配料表 | 按重量递减排列 |
| 过敏原声明 | "Contains: Egg"（含有：蛋类） — SFA过敏原标签强制要求 |
| 原产国 | 须标示"Product of China"或"Made in China" |
| 净重/净含量 | 使用公制单位 |
| 日期标示 | "Best before"（此日期前最佳）或"Use by"（此日期前食用） |
| 贮存条件 | 如产品需要特定贮存条件 |
| 进口商信息 | SFA持牌进口商名称和地址 |
| 营养信息面板 | 大多数预包装食品须强制标示 |

## 风险提示

- **氟喹诺酮类和替米考星残留**是中国蛋品在新加坡边境被拒的最常见原因 — 确保这些物质残留为**零**
- **SFA在入境口岸进行进口检查** — 不合规货物将被扣留、销毁或退运，费用由进口商承担
- **SFA公开发布召回和拒绝通知** — 不合规会损害品牌在这个小而紧密的市场中的声誉
- **认可资格暂停**可在禽流感暴发期间迅速发生 — 关注SFA通告和ADOS状态
- **TradeNet许可时间** — 进口商须在货物到达**之前**持有许可；许可处理延迟可能导致港口仓储费用

## 行动清单

- [ ] 确认海关总署注册有效（第249号令）
- [ ] 在SFA ADOS数据库中确认中国的"蛋及蛋制品"认可状态
- [ ] 联系持有有效贸易商执照的新加坡SFA持牌食品进口商
- [ ] 确保进口商在每批货物发运前申请TradeNet进口许可
- [ ] 检测**氟喹诺酮类和替米考星** — 须为不得检出
- [ ] 检测氯霉素 — 须为不得检出
- [ ] 确认重金属水平符合附表十限值
- [ ] 准备含有所有SFA必填字段（包括过敏原声明）的英文标签
- [ ] 在标签上标注营养信息面板
- [ ] 关注SFA《2025年食品安全与保障法》实施动态
