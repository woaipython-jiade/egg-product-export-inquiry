# /src/content — Content Collections (Markdown)

Astro content collections using glob loader. Each collection has EN files at root and ZH files in a `zh/` subfolder.

| Folder | Collection | Description |
|--------|-----------|-------------|
| `markets/` | markets | Market access detail pages — status, documents, authorities, risk notes |
| `markets/zh/` | markets | Chinese translations of market pages |
| `guides/` | guides | Compliance and regulatory process guides |
| `guides/zh/` | guides | Chinese translations of guide pages |
| `config.ts` | — | Zod schemas defining frontmatter structure for each collection |
