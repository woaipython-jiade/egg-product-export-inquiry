# /src — Application Source Code

All Astro application source code lives here.

## Directory Structure

| Folder | Description |
|--------|-------------|
| `components/` | Reusable Astro UI components (Header, Footer, StatusBadge, LanguageSwitcher) |
| `content/` | Markdown content collections — market pages and compliance guides (EN + ZH) |
| `i18n/` | Internationalization — UI string translations and locale utility functions |
| `layouts/` | Page layout templates (BaseLayout wraps all pages with header/footer/fonts) |
| `pages/` | Astro file-based routing — `/en/` and `/zh/` locale-prefixed page templates |
| `styles/` | Global CSS — Tailwind directives and base styles |
