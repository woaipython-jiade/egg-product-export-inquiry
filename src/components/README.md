# /src/components — Reusable UI Components

Astro components shared across multiple pages.

| Component | Description |
|-----------|-------------|
| `Header.astro` | Site header — logo, navigation links, language switcher, mobile menu |
| `Footer.astro` | Site footer — legal disclaimer and copyright notice |
| `LanguageSwitcher.astro` | EN/中文 toggle button that swaps locale prefix in URL |
| `StatusBadge.astro` | Colored badge for market status (Open=green, Restricted=amber, Closed=red) |
